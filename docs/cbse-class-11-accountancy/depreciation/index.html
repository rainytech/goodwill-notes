Points students often miss

  • Straight Line Method: annual depreciation = (Cost − Scrap Value) ÷ Useful Life.
  • Written Down Value Method: the rate is applied to the reducing book value each year.
  • Freight and installation charges are added to the cost of the asset.
  • On sale, charge depreciation up to the date of sale before finding profit or loss.
  • With a Provision for Depreciation Account, the asset stays at original cost in the books.
